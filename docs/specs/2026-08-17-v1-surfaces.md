# Portfolio v2 — v1.0.0: The Four Surfaces

Date: 2026-08-17
Status: approved direction
Amends: `2026-08-13-design-language.md` — Law 4 only. Every other law, the token
system, Suisse Int'l, and the tier model stand unchanged.

## Why this document exists

v0.6.0 shipped a three-rail home, an archive, prose case pages, and living
counters. The site is coherent but incomplete: there is no gallery, no colophon,
and the case pages are prose where the work is visual. This document settles the
four surfaces the site ends at, and the one law that had to move to get there.

## Scope

Locked and out of scope: the monochrome two-skin token system, Suisse Int'l +
Suisse Mono, hairline separation, the tier model in `data/work.ts`, the shared
primitives in `components/ui.tsx`. No accent hue enters the site.

Settled here: the motion law, the surface set, the case page structure, the
now-playing treatment, the colophon easter egg, and the asset pipeline.

## References

**intempus.org** — mono section labels over hairline rules, label/value spec
tables, and a colophon whose easter egg is a valence/activation scatter: the
cursor blends hue from the nearest points, a click commits, the tint holds
across navigation and resets on refresh. The structure and the *mechanic* carry
over. The warm paper and the serif do not.

The supplied mockups settled the home composition (nav pills, positioning line,
selected row, dated work list, halftone disc bottom-right), the feed as a
framed-tile grid, and the case page as a metadata rail beside a media column.
Their orange and their photography are reference, not direction.

## The amendment

Law 4 read *"Nothing moves unless touched."* It now reads:

> **4. Nothing moves unless touched, or arriving.**

An element may animate the first time it enters the viewport. Once. It does not
re-trigger when scrolled back to, because a reveal that fires twice is a
performance rather than an arrival. Everything after the arrival is
pointer-driven, exactly as before.

Still forbidden, and these are the teeth in the law: no parallax, no
scroll-linked transforms, no autoplay, no ambient loops, no animation that
continues while the visitor is still. A page at rest must be identical to a
screenshot of itself.

`prefers-reduced-motion` renders everything in its final position immediately.

**Why it had to move.** The old law was written against a site with no imagery.
A gallery of static tiles that all exist at once has no way to introduce itself,
and the eye reads the whole grid as a single texture. Arrival gives the grid an
order to be read in. That is a legibility argument, not a decorative one, which
is why the exception is narrow: arrival only, once only.

## Surfaces

Four, and the nav names all four.

| Route | Holds |
|---|---|
| `/` | The argument — profile lockup, selected work, the work list |
| `/work` | The archive, tiered, filterable. Unchanged in kind |
| `/feed` | The gallery |
| `/about` | The record about the person, and the colophon |

`/work/[slug]` sits under Work. `/system` and `/changelog` stay live and stay
out of the nav; the colophon absorbs what `/system` documented and links to both.

**Known cost of this choice.** The colophon loses its own screen, and with it
some of the ceremony intempus gives the same content. The easter egg lives in an
About section instead. Accepted deliberately to keep the nav at four.

## Home

Nav pills top-left, email top-right. Name and positioning line. Then two records:

- **SELECTED** — a horizontal row of case cards: media frame over title,
  one-liner, year, and a value strip.
- **WORK** — dated rows with small thumbs, absorbing the project and index tiers.

### The value strip

The mockups give each project a row of colour dots. Monochrome cannot take that
literally, so the strip carries the project's **real brand palette, desaturated**
— genuine metadata rendered in the site's own register. On hover the strip
returns to full colour, which is pointer-triggered and therefore lawful, and
which makes the restraint legible by showing what it is holding back.

Authored as `palette?: string[]` on `WorkItem`. Absent means no strip; the site
does not invent a palette it does not have.

## Feed

A column-masonry grid of framed tiles at mixed aspect ratios.

- **Arrival** — tiles rise and fade in document order, staggered, once.
- **Hover** — the existing tile feel: lift 120ms ease-out, scale 1.015, border to
  `--ink-3`, settle on a 400/32 spring.
- **Open** — a lightbox with arrow-key paging and escape to close, focus trapped
  and restored to the tile that opened it.
- **Chrome as content** — filter chips by kind, an honest count, a real
  last-updated.

## Case pages — hybrid reel

A sticky left rail beside a single centre media column.

**Rail**: back chip, title, one-liner, and a label/value record — Client, Year,
Role, Discipline, Stack, Live.

**Column**: an ordered list of typed blocks.

```ts
type CaseBlock =
  | { kind: "full"; src: string; alt: string; caption?: string }
  | { kind: "pair"; items: [Media, Media] }
  | { kind: "text"; heading?: string; body: string[] }
  | { kind: "quote"; body: string; attribution?: string };
```

`blocks` replaces `sections` on `WorkItem`. Text blocks are narrow and sit at
decision points, so the argument stays readable without a wall of prose before
the first image. A case page with no blocks keeps the existing honest empty
state — the site still refuses to pad.

## Now-playing — the halftone disc

One component answers three asks: the interactive halftone at bottom-right, the
Spotify carry-over, and the monochrome rule.

A fixed ~120px canvas disc, bottom-right. The live album artwork is converted to
grayscale and rendered as an ordered-dither dot field — **dithering is what makes
this lawful**: it strips the colour rather than suppressing it, so real artwork
enters the site without an accent hue entering with it.

- **Cursor** — dots displace away from the pointer with distance falloff and
  settle on a spring. The animation frame loop runs only while the pointer is
  inside or dots are still settling, then stops. Nothing loops.
- **Hover or focus** — expands into a label/value record: track, artist, elapsed.
- **Silent** — dots settle into a still, uniform grid. Nothing playing is a
  normal answer, as it already is in the counters.
- **Reduced motion** — static field, no displacement.

The artwork is proxied through a same-origin route so the canvas is never
tainted and `getImageData` stays available.

## Colophon easter egg — the value field

intempus tints by hue. Monochrome cannot, so the same mechanic moves one axis
over: a scatter of labelled points on **weight × contrast**.

The cursor blends the nearest points and writes the result to the site's own
token variables, so the whole page shifts tonal register live. A click commits
the blend. It holds across client-side navigation and resets on refresh.

This is Law 3 — *if it changes, it remembers* — and it rhymes with the DialKit
rather than competing with it: the DialKit tunes structure, the value field
tunes tone.

## Assets

`public/` is empty today and art is authored by hand, so the pipeline is built
for dropping files in.

- Art lives at `public/work/<slug>/` and `public/feed/`.
- `scripts/manifest.mjs` scans both, reads intrinsic dimensions straight from
  PNG and JPEG headers — no image dependency — and writes a typed
  `data/assets.generated.ts`.
- Dimensions ship with the manifest, so no frame ever causes layout shift.
- Until art lands, frames render as labelled placeholders printing the slot's
  aspect ratio. An empty frame states what is missing rather than collapsing.

## Guarantees

Invariants. A change that breaks one is a bug.

- A page at rest is identical to a screenshot of itself. Nothing animates while
  the visitor is still.
- No reveal fires twice on the same element.
- `prefers-reduced-motion` renders every surface complete and static, with all
  functionality intact.
- The lightbox is fully keyboard-operable and returns focus to its opener.
- The value field and the halftone disc are enhancements. With JavaScript
  unavailable the pages still read as complete records.
- No accent hue is introduced by any of it. Colour appears only where the visitor
  holds a pointer on a value strip.

## Mobile

Mobile stays its own layout. The disc moves inline into the footer record rather
than floating over content on a small screen. The feed drops to two columns, then
one. The case rail becomes a band above the media column rather than a sidebar.

## Build order

1. **Foundations** — entrance-once primitive, asset manifest, placeholder frame.
2. **Disc** — API extension, art proxy, halftone canvas.
3. **Home** — nav, lockup, selected row, work list.
4. **Feed** — grid, arrival, lightbox.
5. **Case** — block model and reel.
6. **About** — record, colophon, value field.
7. **Ship** — changelog, README, deploy, record the URL.

## Versioning

Ships as **v1.0.0**: the surface set is complete. A `data/changelog.ts` entry
lands before the deploy, `scripts/deploy.sh` runs both faces, the immutable
workshop URL is recorded in the entry, then commit, tag, push.
